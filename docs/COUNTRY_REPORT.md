# Country Report — European leagues (Step 15)

Dataset `data/europe/europe-2026-27.json`, generated by `build/generate-europe-dataset.py` (season 2026-27,
19 Sep 2026 – 30 Jun 2027). Every league below imports, schedules inside the season, produces standings and finishes
with a champion and its promotion/relegation (`EuropeDatasetTests`). Import it into a new game, not together with
the Italian sample.

## 1. Status legend

| Part | Status |
|---|---|
| Competition names, division hierarchy | **Complete** for every country (official names; sponsor names where the league uses them) |
| Format (size, legs, phases, playoffs, promotion/relegation) | **Complete** as data. *Verified 2026-27*: checked against 2026-27 sources. *2025-26 basis*: last known regulations, 2026-27 changes not verified. *Simplified*: the engine cannot express the real rule (§3) |
| Season calendar | **Partial**: one shared season; each league starts on its own offset (26/27 Sep 2026), weekly rounds (6 days where the schedule needs it), playoffs in May–June. Real matchday dates, national-team windows and cup breaks are not modelled |
| Registration rules | **Partial**: squad nationality limits where known (approximate: homegrown/locally-trained rules are modelled as domestic nationality); *none* = not configured |
| Clubs | **Placeholder** everywhere: fictional clubs named after real cities, with reputation, budget and board expectation by division and position. Real clubs come with the real-world database (Step 16) |
| Players, contracts | **Missing** everywhere (Step 16). Without players every match is a forfeit, so the dataset is not yet a playable career |

constant: the promotion places of each second division equal the relegation places of the division above. Second

Kingdom (`Country.IsEuEea`).

## 3. Engine gaps found

| Real rule | Where | Handled as |
|---|---|---|
| Clubs entering a domestic competition mid-season (ABA League clubs in the playoffs) | Serbia, Croatia, Slovenia | Not modelled; the domestic league runs without them. The ABA League itself is an international league for Step 18 |
| Relegation play-outs / promotion-relegation playoffs between divisions | Greece, Italy, several second tiers | Direct relegation |
| Two-legged aggregate ties | United Kingdom | Best-of-3 series |
| Final-four playoff rounds | Primera FEB | Best-of series |
| Promotion subject to licensing; closed leagues | Lithuania, United Kingdom, BNXT | Sporting promotion only; closed leagues as separate leagues |
| Homegrown / locally-trained player rules | Spain, France | Domestic-nationality minimum |
